# How to use:

1. Find plugin folder
2. Drag specific file under folder
3. Open a studio instance to use

# Specific plugin instructions:

## SoloDataStore:
1. Install system
2. Install `@CHL>SoloDataStore`

Api for this is similar to `DataStoreService`.

## QuickAssetImporter Api
1. Install system
2. Install `@CHL>PluginAssetImporter`
